LESS GUESSWORK

Small routines.
A system you understand.

Bring the checks you keep meaning to run into one place. See the finding, understand the next step, stay in control.

01 / NOTICE

Find what needs care.

Check Nix, disk space, retained generations, and the age of your flake inputs. Linux adds memory pressure and service checks. Get readable advice or JSON for your own tools.

nixcare doctor
02 / MAINTAIN

Make room thoughtfully.

Store optimisation shares identical files. NixOS cleanup previews its plan, keeps recent generations, and protects the selected, running, and booted system.

nixcare clean --dry-run NixOS
03 / PREPARE

See the update ahead.

Compare upstream flake inputs without editing your lockfile. On NixOS, build a candidate first, review the package changes, then explicitly apply it when you’re ready.

nixcare check-updates --flake .

MEET YOUR NEW ROUTINE

Start with one check.

Already have Nix? You’re ready. Pick the setup that fits. Flake commands need nix-command and flakes enabled.

A useful first look.

Run a read-only scan on Linux or macOS. Add your configuration path to include flake freshness.

nix run github:mteyra/nixcare
nix run github:mteyra/nixcare -- scan --flake /path/to/config

Keep care close by.

Install the CLI into your Nix profile. Declarative and Home Manager setup is also documented in the README.

nix profile add github:mteyra/nixcare
nixcare doctor
nixcare check-updates --flake /path/to/config

Let the routine run itself.

Add the flake input, then include this module in your NixOS configuration. See the README for a complete example.

# After adding inputs.nixcare.url = "github:mteyra/nixcare";
modules = [
  nixcare.nixosModules.default
  {
    services.nixcare = {
      enable = true;
      flakePath = "/etc/nixos";
      hostName = "your-host";
    };
  }
];

NEW TO NIX?

A care routine for a
reproducible computer.

Nix describes software and system configuration in code. That makes a computer easier to rebuild and roll back—but it still needs attention: disk space, aging dependencies, and updates that may fail to build.

Nixcare turns that maintenance into repeatable checks and visible next steps. It’s a small open-source engineering project about making a powerful ecosystem easier to live with.

Nixcare is a community project, independent of the NixOS Foundation. It doesn’t install Nix, guarantee security, or automatically tune your hardware.
